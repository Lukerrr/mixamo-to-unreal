mixamo → unreal

Add a root bone and root motion to Mixamo animations for Unreal Engine.

    Why does Unreal need a root bone?

    Mixamo skeletons start at the Hips bone. Unreal Engine takes root motion from the top bone of the skeleton, so without a separate root bone the character can't move its capsule. This tool adds a root bone and moves the walking motion from the hips onto it.

    What does it change in the file?

    It adds a root bone, moves the horizontal hips movement onto it (and, if you want, the turning too) and renames bones to the UE Mannequin names: pelvis, spine_01, thigh_l and so on. The animation looks exactly the same as before.

    With Skin or Without Skin?

    Both work. Download from Mixamo as FBX Binary. A file with skin keeps its mesh, a file without skin stays skeleton only.

    How do I import it into Unreal Engine?

    Import a converted character with skin first. For animations without skin, pick that character's skeleton in the import dialog. To use root motion, turn on Enable Root Motion in the Animation Sequence.
